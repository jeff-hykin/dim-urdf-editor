# dim-urdf-editor

A URDF frame-tree viewer/editor — an installable DimOS dashboard app.

```
dim install https://github.com/jeff-hykin/dim-urdf-editor
```

## dimOS Desktop

On the new (Rust) dimOS Desktop:

```sh
dimos-desktop install https://github.com/jeff-hykin/dim-urdf-editor --ref dimos-desktop2
```

The package is described by `dimos.yaml`; its install step (`nix run .#install`) pre-caches the backend's imports.
